Capture Engine Documentation

High-Performance Open Source Screen Recording

About The Program

The Capture Engine is a high-performance, open-source screen, region, and audio recording utility built natively for Windows. It utilizes the DirectX Desktop Duplication API, Windows Media Foundation, WASAPI, and hardware encoding (NVIDIA NVENC, AMD AMF, Intel QSV) to achieve zero-drop, near-lossless 4K recording.

Compilation & vcpkg Instructions

To compile this project from source, you will need Visual Studio 2022 (with C++ Desktop development) and vcpkg installed for dependency management.

1. Install vcpkg dependencies

Run the following command in your terminal to install the necessary DLLs and libraries for a 64-bit Windows build:

vcpkg install ffmpeg imgui spdlog nlohmann-json taskflow openssl zlib --triplet x64-windows

2. Build the Application

You can use CMake and Ninja to build the application. From the `Capture` directory:

cd Capture
cmake -B build -G Ninja
cmake --build build

Shortcut Keys

These global hotkeys work even when the application is minimized or in the background:

  • F9 - Start / Stop Recording
  • F10 - Take Screenshot

User Interface Menus

1. Main Settings Tab

  • Quality Preset: Choose between Lossless, High, Medium, or Low. This adjusts the CRF/QP values dynamically for hardware encoders.
  • Output Resolution & FPS: Set the target dimensions (e.g., 3840x2160, 1920x1080) and target frame rate (up to 120 FPS+).
  • Codec & Container: Choose H.264, H.265 (HEVC), or AV1. MKV is the recommended container to prevent corruption on crash.
  • Output Folder: Where your `.mkv` files and screenshots are saved.
  • Mouse Cursor: Toggle visibility, add click highlight rings, and customize highlight colors.

2. Capture Sources Tab

  • Display Capture: Select which monitor to capture using Desktop Duplication.
  • Region Capture: Set specific X, Y, Width, and Height coordinates to record a portion of the screen.
  • USB Capture Devices: Select webcams or capture cards (e.g., Elgato, generic USB video).
  • Camera Stream (IP/URL): Enter an RTSP/HTTP URL to record from network security cameras. (Overrides local capture).

3. Diagnostics Tab

  • System Memory: Live view of RAM usage. The engine utilizes large empty RAM blocks to buffer video frames, preventing stutters.
  • Selected GPU Info: View dedicated VRAM and capabilities (H.264/H.265/AV1 Encode/Decode support).
